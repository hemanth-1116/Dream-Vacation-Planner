# 🌴 Dream Vacation Planner ✈️

Welcome to the **Dream Vacation Planner**, a one-stop web app to explore, dream, and plan your perfect getaway. Whether you're craving the beach breeze, mountain views, or just some random chai in a hill station – this app has your back!

## 🧠 Features

- 🏖️ **Explore Places** – Find the best spots categorized for travel, food, or stay.
- 📍 **Geolocation Support** – Suggests places based on your current location.
- 🔍 **Smart Search** – Filter places with keywords or categories.
- 📸 **Attractive Cards** – Each place comes with stylish cards and smooth animations.
- 🧭 **Sticky Navbar & Smooth Scroll** – Scroll like butter 🍞
- 🎬 **Video Overlay with Gradient** – Welcome screen with a cinematic vibe.
- 📱 **Fully Responsive** – Mobile, tablet, desktop... looks fab on all!
- 🌀 **Loading Skeletons** – No more boring spinners. See content loading in style.

## 🛠️ Tech Stack

- **Frontend:** React.js + Tailwind CSS
- **API Integration:** RapidAPI (Geo & Places APIs)
- **State Management:** React Hooks & Props
- **Routing:** React Router
- **Styling:** Custom CSS + Tailwind for that fancy vacation feel ✨
